# Exam Project
## TechFlow Solutions
This project was created as part of the "Version Control with Git" course.

### Project Description
TechFlow Solutions is a simple landing page created using HTML and CSS.

The project demonstrates:
- HTML5 structure
- CSS styling
- Git version control
- GitHub repository management
- Branch creation and merging
- Merge conflict resolution

### Technologies

- CSS3
- Git
- GitHub
